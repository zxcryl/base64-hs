base64-hs
---------

A base64 encoder and decoder written in haskell

This silliness was inspired by Dave Eddy's bash implementation of the same program


Decode/Encodes data to/from base64 from stdin and outputs to stdout

# Usage
Usage: `base64 [OPTIONS]`

```
Options
  -h, --help
          Show this help message
  -d
          Decode from base64
```
